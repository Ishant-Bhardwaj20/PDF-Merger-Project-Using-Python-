# PDF Merger Using Python :-
This project is a simple PDF Merger application that I created using Python to improve my understanding of practical Python concepts and learn how Python can be used to build real-world applications.

The application provides a simple graphical user interface where users can select multiple PDF files, view the selected files in a list, and merge them into a single PDF file. After merging the files, the user can choose a location and name for saving the final merged PDF.

While building this project, I focused on understanding how different Python libraries can work together to create a functional desktop application. I used Tkinter to create the graphical user interface and the `pypdf` library to handle the PDF merging process.

The project also includes basic error handling. For example, if a user tries to merge files without selecting any PDFs, the application displays an error message. It also handles unexpected errors that may occur during the merging process and provides feedback to the user.

## Features :-
* Select multiple PDF files
* Display selected files in the application
* Merge multiple PDFs into a single PDF
* Choose the file name and location for the merged PDF
* Simple graphical user interface
* Basic error handling and user-friendly messages

## Technologies and Libraries Used :-

* Tkinter
* pypdf
* os module
* pypdf
* pdfwriter
